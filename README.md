# Praktikum Python Dasar

Repositori ini berisi hasil praktikum Python Dasar (Materi 02) dengan mengikuti 19 bab tutorial Santrikoding.

## Materi yang Dipelajari
1. Pengenalan & Instalasi Python
2. Struktur Dasar Program Python
3. Tipe Data
4. Variable
5. Konstanta
6. Operator
7. Control Flow
8. Function
9. List, Tuple, dan Set
10. Dictionary
11. Class & Object (OOP Dasar)
12. Encapsulation
13. Inheritance
14. Polymorphism
15. Abstraction
16. Exception Handling
17. File Handling
18. Module
19. Package

## Struktur Proyek
- `python-dasar.py` : kode seluruh bab
- `alat_hitung.py` : contoh module (bab 18)
- `alat/` : contoh package (bab 19)
- `screenshots/` : bukti hasil eksekusi tiap bab
