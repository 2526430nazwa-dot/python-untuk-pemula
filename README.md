# Python untuk Pemula

Latihan belajar Python dari nol mengikuti panduan Santrikoding.

## Materi yang dipelajari

- Variabel dan tipe data: `print()`, integer, float, string, boolean
- Operator: aritmatika, perbandingan, dan logika
- Perulangan: `for`, `while`, `break`, `continue`
- Lists dan dictionaries

## Cara menjalankan

1. Buat dan aktifkan virtual environment:

   python -m venv venv
   .\venv\Scripts\Activate.ps1

2. Pasang dependensi (jika ada):

   pip install -r requirements.txt

3. Jalankan program:

   python latihan.py
